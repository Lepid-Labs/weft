# UC-005 New developer explores the project on day one

A new developer runs `weft serve` on day one, wanting to understand the project without needing a guided tour.

## Preconditions

The project has a README or a designated entry-point document.

## Primary flow

1. Weft opens at the README or the designated entry-point doc.
2. The developer follows links from design intent to implementation.
3. The developer follows links from implementation to the API contract.
4. The developer follows links from the API contract to the database schema.

## Postconditions

The developer has explored the full project graph on their own, without a guided tour.
